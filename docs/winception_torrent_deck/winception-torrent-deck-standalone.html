03 / Flow

1

Publish / Sync

Generate or reuse torrent artifacts.

2

Start Services

HTTP → TFTP → DHCP → tracker + seeder.

3

boot-session

Client receives torrentEnabled + metadata.

4

SMB Validation

Selected WIM must already exist via SMB.

5

aria2 P2P

New-OSDisk → .torrent → BT staging.

5F

Fallback

Torrent gate/download/hash failure → $null.

6

Local WIM

Verify SHA256 and use C:\OSDCloud\OS.

6F

SMB WIM

Keep previously mapped SMB ImageFile.

7

Invoke-OSDCloud

Apply Windows from the selected ImageFile.

8

Seed + Wait

Keep aria2 alive through apply and seed wait.
