問題

Lite Touch 耗人力，經典 Zero Touch 耗機房與頻寬

兩者都在「灌映像」。差在人要不要點精靈、以及 N 台電腦要不要各從同一台伺服器拉一份完整 WIM。

MDT Lite Touch

人跟著電腦走

  • 每台要選工作序列、電腦名稱、應用程式
  • 產業常見在場時間 45–90 分鐘／台
  • 勞動約 USD 26–82／台（時薪 35–55 估算）
  • 驅動目錄要人工維護，新機型就重來
經典 Zero Touch · MDT／SCCM

人少了，佇列還在

  • 免精靈，但仍是一台 DP 對 N 台送 N 份 WIM
  • SCCM + SQL + 發佈點：建置與授權成本
  • 每機型仍要維護 driver package
  • 完成證明多半留在伺服器 log，難交班

工時與美元為產業常見區間，不是本產品實驗室數字。Winception 不取代 Windows Autopilot（那是雲端註冊，不是 PXE／USB 映像部署）。

產品

技術人員準備 runtime、Windows 映像與 deployment profile。目標電腦從 UEFI IPv4 PXE（或離線 USB）開機後，WinPE、OSDCloud、SetupComplete、應用程式與自訂腳本會一路跑到桌面就緒。

PXE／USB→ WinPE→ OSDCloud 套用映像→ SetupComplete→ 軟體／腳本→ windows-desktop-ready

操作員在瀏覽器

資料面自動供料

DHCP、TFTP、HTTP、SMB，加上 Torrent P2P 分攤 OS WIM。

每台都有證據

Fleet、Activity、Validation Evidence：完成、失敗、卡在哪一階都看得到。

開源基底

站在 OSDCloud 上，而不是從零重寫成像引擎

OSDCloud 是 David Segura／OSDeploy 的開源 PowerShell 部署框架，社群與文件成熟，PowerShell Gallery 可安裝。Winception 用它處理 WinPE 套用 Windows，再補上可帶走的主機、Web 與 P2P。

OSDCloud 本身就擅長的事

  • WinPE 裡下載或套用 Windows 10／11
  • Dell、HP、Lenovo、Surface 官方 Driver Pack
  • Get-MyDriverPack 依 SMBIOS 廠牌／型號選包
  • 沒有官方包時可走 Microsoft Update Catalog

Winception 加在上面的事

  • 本機 WIM 快取，不依賴每台去抓 Microsoft ESD
  • Torrent P2P 讓多台互傳映像
  • Web Console、profile、軟體目錄、Evidence
  • PXE Secure Boot、既有 DHCP 配對、USB 離線

公開來源：osdcloud.com、github.com/OSDeploy/OSD、PowerShell Gallery 套件 OSD。

W Winception
開源引擎 + 產品化控制面
彈性

全程 PowerShell，改規則不必改成像核心

部署主機、WinPE、第一次開機、登入後安裝都是腳本。比 MDT task sequence XML 更好讀、更好審、更好為單一客戶改一條規則。

兩種加軟體的方式

Guided installer：選 MSI／EXE，由系統產生靜默安裝腳本（MSI 預設成功碼 0、1641、3010）。

Custom PowerShell：帶 payload 與受信任管理員的 install.ps1，先做 Windows PowerShell 5.1 語法檢查。

執行契約

  • 順序由 profile 的 installSequence 決定
  • 任一步失敗、缺檔或逾時 → fail-fast，後續不跑
  • 登入後以 SYSTEM 任務安裝，畫面顯示即時耗時
  • Evidence 只記步驟名、狀態、秒數，不含秘密

需要外網的安裝放在登入後序列；映像套用階段只連 Winception 主機。

新的 Windows 版本、語言，加進 Cache 就能部署

1.000×

同波次多台互傳，host 大約只供一份 WIM

BitTorrent：本機 HTTP tracker + host seeder + WinPE aria2。Host 用 striped bitfield 把片交錯分給同批 client，讓它們邊下載邊互相上傳。

已實測 · 2026-06-19

WIM 6,368,481,430 bytes（約 5.93 GiB）

兩台 Secure Boot client 各拿一半 stripe

Host 該波次送出剛好 1.000×，不是 2.000×

互傳各約 3.18 GiB · SHA-256 通過 · 皆達桌面就緒

180 秒沒進度才回落 SMB 直傳。四台併發連續兩輪（2026-06-20）8／8 桌面就緒。這是頻寬證據，不是保證任意場地的牆鐘時間。

現場敘事：LTI 是人跟著電腦、50 台要數個工作天。經典 ZTD 人少了，下午還在等最後一波 DP。Winception 把開機潮放進同一波 P2P；機房成本從 WDS／SCCM／SQL 收到一台筆電。請代入貴單位時薪與台數，不要把美元區間當成產品保證。

P2P 1.000× 是 repo 實測；人時與美元是產業區間。

帶走的三句話

開源引擎、一份 WIM、瀏覽器交班

  • 成像核心是知名開源 OSDCloud，驅動依廠牌型號自動抓。
  • PowerShell 讓軟體與自訂腳本進 profile；新 Windows 版本與語言加進 Cache 就能佈。
  • P2P 讓 host 大約只供一份映像——這是相對 LTI／經典 ZTD 最大的時間與頻寬差。
  • Web Dashboard 與 Evidence：人不必站在伺服器前，完成證明跟得上每一台。
現場怎麼用：準備一次 → 開服務 → 電腦 PXE → 必要時核對配對碼 → 看部署活動 → 全部就緒後停服務。換場地只改介面，映像與 profile 帶走。
